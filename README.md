# Full Stack Developer Portfolio

Single-page futuristic portfolio prototype built around HTML, CSS and JSX.

## Files

- `index.html` — page shell and metadata
- `styles.css` — responsive visual system, glassmorphism and animations
- `app.jsx` — JSX components, content and interactions
- `resume.pdf` — add your real resume here

## Personalization

Edit the `portfolio` object at the top of `app.jsx`:

- name
- email
- GitHub
- LinkedIn
- resume path

Also replace `[DATES]`, `[COMPANY NAME]`, and other placeholders.

## Important

The standalone prototype uses React and Babel from CDN solely to render JSX in a browser without a build setup. If you import this into Lovable, let the environment handle the JSX build/runtime while preserving the single-page architecture and the HTML/CSS/JSX-only design requirement.
